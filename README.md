# Modern Landing Page

This project is a responsive landing page built with HTML, CSS, JavaScript, Shards UI (v3.0.0), and Bootstrap 4. It features a clean design and includes dark mode support.

## Key Features

*   **Responsive Navbar**: With navigation links (Home, Features, Pricing) and a theme toggle button.
*   **Hero Section**: Welcoming visitors with a title, subtitle, and call-to-action buttons.
*   **Features Section**: Showcasing three key features with descriptions and links.
*   **Footer**: Standard copyright information.
*   **Dark Mode**: Toggle between light and dark themes, with preference saved in `localStorage`. Uses the `bootstrap-dark` theme.

## How to View

1.  Clone or download the repository.
2.  Open the `index.html` file in your web browser.

## Technologies Used

*   HTML5
*   CSS3 (via Shards UI, Bootstrap 4, and `bootstrap-dark`)
*   JavaScript (for theme toggling)
*   [Shards UI v3.0.0](https://designrevision.com/docs/shards/) (Bootstrap 4 based)
*   [Bootstrap v4.5.2](https://getbootstrap.com/docs/4.5/getting-started/introduction/)
*   [bootstrap-dark theme by vinorodrigues](https://github.com/vinorodrigues/bootstrap-dark)
*   [Font Awesome](https://fontawesome.com/) (for icons, via CDN)
